DEFECT FOUND AND FIXED DURING THIS STAGE
- `SERVICE_PASSWORD=` was not flagged. The generic assignment rule used `\b` on
  both sides of the keyword; there is no word boundary between `_` and
  `PASSWORD`, so underscore-prefixed names were skipped. The rule now uses
  explicit non-alphanumeric lookarounds, and two regression tests cover
  `SERVICE_PASSWORD` / `db_password` detection and rejection of keywords embedded
  in larger identifiers (`mypasswordcontext`). Unit tests: 72 → 74.
