--------------------------------------------------------------------------------
6. WHAT WAS NOT DONE
--------------------------------------------------------------------------------
- No TLS and no authentication on :8300. The API is unauthenticated by design in
  this project; exposure is controlled at the security list (single /32). Do not
  widen `scanner_allowed_cidr`; the variable rejects 0.0.0.0/0.
- No teardown: the instance is running and billing against trial credits. Destroy
  only on operator request (`tofu plan -destroy` → `tofu destroy`).
- Single instance, no load balancer, no backups. This is a verification
  deployment, not a production HA topology.
- A1.Flex could not be obtained in eu-frankfurt-1 at deploy time; the AMD micro
  shape is the deployed fallback (documented above).
